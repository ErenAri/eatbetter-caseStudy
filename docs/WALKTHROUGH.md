# Suggested 7-minute walkthrough

1. **0:00–0:45 — Thesis:** wrong-and-confident is more harmful than a targeted question.
2. **0:45–2:15 — Demo:** Today, photo/context, uncertainty review, correction, confirmation, detail.
3. **2:15–3:45 — Grounding:** provider boundaries, retrieved candidate constraint, deterministic math.
4. **3:45–4:45 — Reliability:** states, idempotency, bounded retries, ownership, private storage design.
5. **4:45–5:45 — Measurement:** baseline/hybrid/oracle harness, metrics, error taxonomy, and why results
   remain explicitly unmeasured without consented data and live credentials.
6. **5:45–6:30 — Trade-off:** deliberate clarification cost and configurable materiality thresholds.
7. **6:30–7:00 — Next:** collect/label the private dataset, run the live development/holdout protocol,
   and only then rank the next three accuracy changes from measured failures.
